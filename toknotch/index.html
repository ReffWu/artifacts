悬停速览 · 进度与重置窗口

光标移至指示环，即刻展开精确限额窗口与重置时间倒计时。Claude 环与官方 /usage 严格保持一致。

展开全貌 · 实时会话与模型配额

点击展开全景面板，清晰罗列正在后台运行的任务、等待人类反馈的会话，以及各模型额度的实时百分比。

原生质感，为专注编码设计

零配置 · 凭证无感直读

无需手动输入任何 API Key。自动借用本机已登录工具的 Keychain 与本地会话，既保安全，又省心力。

忙碌感知 · 旋转与脉冲

薄弧旋转提示后台仍在极速生成；脉冲琥珀光环提示会话正阻塞等待你的输入。随时掌握全局节奏。

边缘自适应 · 刘海无缝融合

吸附顶部时完美融入 MacBook 硬件刘海；吸附左/右呈现小巧纵列；吸附底部时跟随 Dock 自动贴紧。

轻量原生 · 静默安全更新

Swift 原生开发，毫秒级响应与超低内存消耗。内置 Sparkle 签名更新体系，稳定且随时保持最新。

全方位覆盖主流 AI 编程助手

开发工具 / 平台 读取方式 原理与安全性
Claude Code 官方直读 直读登录钥匙串中的 OAuth 凭据，与官方 /usage 终端输出完全一致；支持多账号隔离。
Cursor 本地会话 直读本地编辑器已登录的 SQLite 会话状态，无需额外登录。
Codex 原生服务 实时查询本地 Codex App Server 的速率限额，未运行时回退至运行日志。
Antigravity / Gemini 本地接口 优先读取本地语言服务器与 Google Quota 接口，清晰展示模型配额。
GLM (智谱) 凭证借用 自动借用 Claude Code、ZCode 或 OpenCode 中已配置的密钥，查询 Coding Plan 额度。
