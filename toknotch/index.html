屏幕右侧停靠 · 气嘴精准对齐

常驻屏幕右侧边沿的深黑 Side Notch。鼠标悬停向左平滑展开毛玻璃卡片，气嘴指针水平直指当前模型环，清晰呈现输入输出 Token 分布、等效 API 价值与请求频次。

屏幕顶部刘海 · 灵活无缝停靠

亦可随心切换停靠至屏幕顶部。气嘴垂直向上精准吸附对应环，与 macOS 顶部菜单栏和硬件刘海浑然一体，绝不遮挡主屏核心工作区。

原生质感，为专注编码设计

零配置 · 装好即用

已内置 tokscale 引擎（MIT 协议），无需安装 Node.js、npm 或 Homebrew。纯本地 SQLite 账本直读，不碰钥匙串、不弹密码框、不上传任何数据。

今日 · 本月 · 累计三环

弧度含义清晰明确：今日对比近 30 天最高单日，本月对比上月同期，累计对比下一里程碑。弧走到 100% 代表超越了自己，而非告警警告。

真实订阅回本计算

在设置中填入月费与扣费日，实时计算当前周期产生的等效 API 价值是订阅费的几倍（还差多少或已超出多少），按真实扣费账期精准核算。
